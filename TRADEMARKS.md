# Trademarks

The code of PISA is free software (LICENSE, protocol/LICENSE). The name is not covered by those licences: this page
says how it may be used.

"PISA" and "Pisa", as the name of this assistant, and its logo (when there is one) are the project's marks, held by
the project's lead maintainer (GOVERNANCE.md). A licence for the code is not a licence for the name.

## What you may do without asking

- Say truthfully that your work uses, is based on, or is compatible with PISA ("built on PISA", "a fork of PISA",
  "a client for PISA servers").
- Run, modify and distribute the code under its licence, and call an unmodified build of a PISA release "PISA".
- Use the name in articles, reviews, talks, teaching and research about the project.

## What needs the maintainers' written permission

- Calling a modified version, a fork, a hosted service or a product "PISA" or "Pisa", or any name that could be
  confused with it.
- Using the name or a logo in a way that suggests the project endorses, sponsors or is affiliated with you.
- Using the name in a domain name, an app store listing, a company or product name, or a social-media handle.

A fork is welcome. Give it its own name, and say it is based on PISA.

## Asking

Open a discussion in the repository's Discussions ("Trademark" category). For a request that should stay private,
contact the repository's maintainers via GitHub: the **Security** tab → **Report a vulnerability**, saying in the
title that it is a trademark request.

Other names in this repository (models, services, libraries, data sources) belong to their owners and are used only
to identify them.
