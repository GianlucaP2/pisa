# Getting help

- **Setting up and running PISA:** start with [docs-site/self-hosting.md](docs-site/self-hosting.md).
- **Questions and ideas:** the repository's **Discussions** (Q&A for questions, Ideas for proposals).
- **A bug:** open an issue with the bug report form. Say which version, how you deploy it, and what you saw.
- **A security problem:** never in public. See [SECURITY.md](SECURITY.md).

PISA is maintained by volunteers, with no guaranteed response time. There is no paid support.

When you share logs or configuration, remove passwords, keys, tokens, addresses and anything personal first.
